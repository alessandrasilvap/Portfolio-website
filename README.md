# 💼 Portfólio Web — Alessandra

Portfólio desenvolvido para apresentar minhas experiências, competências e projetos na área de tecnologia.

O objetivo deste projeto é reunir de forma organizada minhas principais habilidades, experiências profissionais e projetos desenvolvidos utilizando tecnologias web, mobile, cloud e integração de APIs.

---

## 🚀 Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Git & GitHub
- React

---

## 🎨 Sobre o design

O layout foi desenvolvido com foco em um visual moderno, limpo e profissional, utilizando uma paleta de cores escuras para proporcionar melhor contraste visual e destacar os elementos principais da interface.

A estrutura single page foi escolhida para facilitar a navegação e permitir uma visualização rápida das informações mais importantes do portfólio.

---

## 🧩 Seções do portfólio

- Início
- Sobre
- Projetos
- Formações
- Experiências
- Contato

---

## 📌 Funcionalidades

- Navegação suave entre seções
- Layout responsivo
- Cards interativos
- Links para GitHub, LinkedIn e contato
- Destaque para projetos, formações e experiências
- PDF do meu currículo para baixar
- Versão Português e Inglês
